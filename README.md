# Java
## Curso de Java
Java es un lenguaje de proposito general lo que significa que no esta limitado a un solo tipo de apilcacion sino que se puede utilizar en una gran variedad de areas del desarrollo de software desde aplicaciones empresariales hasta sistemas embebidos java ha desmostrado ser versatil y seguro.

## Usos principales de java

### Aplicaciones empresariales
java es el lenguaej pro excelecia por excelencia en el desarrollo de software corprativo, Bancos, Gobierno, Salud, grandes empresas lo usan para construir sistemas criticos, gracias a su estabilidad, seguridad, rendimiento y escalabilidad.

Usado en arquitecturas distribuidas como java EE
potenciado gracias a frameworks como spring boot, quarkus que permiten crear microservicios, API REST, aplicaciones web modernas y de forma rapida y profecional sin necesidad de conocer todas las complejidades de java

Su ecostistema es inmenso y cuenta con una gran cantidad de librerias y herramientas para cualquier tipo de aplicacion que quiera construir,ademas de que java es un lenguaje con un tipado fuerte lo que ayuda a detectar errores en tiempo de compilacion.

### Desarrollo Backend
java es apliamente usado en el desarrollo del lado servidor de aplicaciones web
Con frameworks como Spring Boot, Quarkus pueedo contruir servidores robustos, seguros y altamente configurables
ideal para microservicios, APIs, integracion con basese de datos y ssitemas distribuidos

### Big Data y procesos de datos
java es compatible con plaformas de Big Data como Apache Hadoop, Apache Spark, Apache Flink, Apache Storm, Apache Kafka, entre otros esto lo convierte en una opcion muy fiable para sistemas que requieren procesamiento de grandes volumenes de datos en tiempo real o por lotes.

### Aplicaciones de escritorio
Aunque hoy en dia no es tan popular como antes para el desarrollo de apliaciones de escritorio gracias a la popularidad de las aplicaciones web y moviles, java sigue siendo una opcion muy viable para el desarrollo de aplicaciones de escritorio gracias a frameworks como Swing, JavaFX y Qt que permiten crear aplicaciones de escritorio robustas y profesionales

### Desarrallo Android
Aunque Kotlin es el lenguaje recomendado por Google para el desarrollo de aplicaciones Android, Java sigue siendo una opcion muy viable para el desarrollo de aplicaciones Android gracias a la compatibilidad con la JVM y la gran cantidad de librerias y herramientas disponibles para el desarrollo de aplicaciones Android

### loT (internet of Things / internet de las cosas)
Gracias a su portabilidad y bajo consumo de recursos java se utiliza en dispositivos embebidos, sensores inteligentes o sistemas de control en tiempo real plataformas como java ME y Eclipse IoT lo hacen apto par este tipo de soluciones

## Versiones de java
Existen varias versiones de java cada una con sus propias caracteristicas y mejoras
 
#### java SE (Standard Edition)
 Es la mas basica de java con todo lo necesario para crear aplicaiones de escritorio, librerias, logica de negocio, herramineta de linea de comandos, etc.

#### java EE (Enterprise Edition)
 Extiende java SE con funcionalesdades para el desarrollo empresarial como:

 + servlets
 + EJB (Enterprise JavaBeans)
 + Web Services
 + Seguridad Avanzada
 + Manejo de transacciones
 
 #### JDK (Java Development Kit)
 Es el paquete completo para desarrollo incluye
 + Compilador (javac)
 + La maquina virtual (JVM)
 + Herramienta de desarrollo y depuracion

 #### JRE (Java Runtime Environment)
 Es el paquete que incluye la JVM y las librerias necesarias para ejecutar aplicaciones java

 #### Oracle JDK
 Es la version de java desarrollada por Oracle es la version mas completa y actualizada de java

 #### OpenJDK
 Es una version de java de codigo abierto desarrollada por la comunidad es una version gratuita y de codigo abierto de java



 ## ¿Que es la JVM?
Java es un lenguaje de programacion conocido por su principio de "Escribe una vez, ejecuta en cualquier lugar" (Write once, run anywhere) esto significa que un programa compilado en una plataforma puede ser ejecutado en cualquier otra plataforma que tenga una JVM instalada esto se debe a que java no se compila a codigo maquina sino a bytecode que es un codigo intermedio que puede ser ejecutado por la JVM

La JVM (Java Virtual Machine) es una maquina virtual que se encarga de ejecutar el bytecode de java, la JVM es la encargada de traducir el bytecode a codigo maquina que puede ser ejecutado por la CPU de la computadora

## Lenguaje Orientado a Objetos (OOP/POO)
java esta contruido sobre el paradigma de programcion orintado a objetos lo que significa uqe todo gira en tomo a objetos, clases, herencia, pilmorfismo y encpulsamiento esto permite construir programas modulares, reutilizables y faciles de mantener 

## Fuenertemente tipado
En java cada variabale y exprecion tiene un tipo bien definido y los errores de tipo se detectan en tiempo de compilacion esto reduce muchos errores comunes y mejora la calidadd del codigo

## Lenguaje compilado
Como ya e visto java no es ejecutable directamente desde el codigo fuente primero el compilar javac transforma el codigo .java en bytecode en .class que luego es ejecuta pro la JVM esto combina lo mejor de los dos lengujaes compilados e interpretados lo que permite que java sea un lenguaje con alto rendimineto y con alta portabilidad entre otros lenguajes

## Multiplataforma
La JVM permite que java sea un lenguaje multiplataforma lo que significa que un programa java compilado en una plataforma puede ser ejecutado en cualquier otra plataforma que tenga una JVM instalada

## Gestion automatico de memoria
java incluye un recolector de basura que se encarga de liberar la memoria que ya no se utiliza esto ayuda a evitar fugas de memoriay simplificar el manejo de recursos

como java lleva tanto tiempo en el mercado tiene una cantidad inmensa de librerias, frameworks, herramientas y una comunidad enorme dispuesta a ayudar
